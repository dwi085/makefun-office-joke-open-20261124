A single-line office joke for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty. The program writes exactly one joke — no more than 200 characters — to `/output/entry.txt`: the meeting that could have been an email sends a follow-up email asking for another meeting.

## Run it

```sh
node main.ts
```
